# 기아 EV5 장기렌트 랜딩페이지 (KIA EV5)

기아(KIA)의 전용 전동화 준중형 SUV **EV5**의 장기렌트 견적 비교 및 실시간 맞춤 상담 유도를 위한 프리미엄 다이렉트 랜딩페이지입니다.  
신차를 포함한 모든 EV5 차량 렌트 조건을 투명하게 산출하며, 화이트·라이트 그레이·블랙의 모노톤과 테크놀로지 민트 포인트를 기반으로 한 **Volterra 미니멀리즘 디자인 시스템**을 적용하였습니다. 모바일 최소 360px부터 초고해상도 데스크톱(1,440px+)까지 완벽하게 대응합니다.

## 1. 프로젝트 개요

- **프로젝트명**: 기아 EV5 장기렌트 다이렉트 랜딩페이지 (`rentalCar_kia_EV5`)
- **운영 브랜드**: **핏카컴퍼니 (FitCar Company)**
- **대상 차종**: 기아 EV5 전 라인업 (스탠다드/롱레인지 Air, Earth, GT-Line 공식 6종 트림)
- **핵심 목표**:
  - 신차를 포함한 모든 EV5 장기렌트 조건의 실시간 투명 견적 산출
  - 선납금, 보증금, 연간 주행거리, 계약 기간을 자유롭게 시뮬레이션할 수 있는 원스톱 계산기
  - 실제 출고 고객 23인의 생생한 사진과 후기를 담은 무한 루프 슬라이더
  - 전 디바이스(모바일 360px ~ 1,440px+ 와이드)에서의 무결점 반응형 사용자 경험
  - 불필요한 이탈을 방지하고 전환율을 극대화하는 시네마틱 CTA 및 하단 스티키 견적 바

## 4. 핵심 작업 규칙 및 원칙 (Work Rules & Principles)

### 1) 스타일링 및 CSS 원칙
- **TailwindCSS 엄격 배제**: 오직 순수 Vanilla CSS(`src/styles/index.css`)로만 UI 시스템을 구축합니다.
- **CSS 토큰 시스템**:
  - 배경: Clean White (`#ffffff`), Light Gray (`#f8fafc`, `#f1f5f9`)
  - 텍스트: Deep Black (`#0f172a`, `#111827`), Slate (`#475569`, `#64748b`), Muted (`#94a3b8`)
  - 포인트: Luminous Mint (`#00d2ad`), Tech Teal (`#008b74`), Soft Teal (`#f0fdfa`)
- **인라인 스타일 지양**: 반응형 오버라이드 및 미디어 쿼리가 정확하게 동작하도록 구조적인 전용 CSS 클래스로 관리합니다.

### 2) 브랜드 및 카피라이팅 원칙
- **공식 상호명 및 사업자 정보 준수**: 모든 영역에서 **핏카컴퍼니** 및 **FitCar Company**를 공식 명칭으로 사용합니다.
- **포괄적 렌트 서비스 표현**: 신차로만 서비스를 한정 짓지 않고, 신차를 포함한 모든 EV5 장기렌트를 아우를 수 있도록 일관되게 **`장기렌트`** / **`EV5 장기렌트`** 표현을 적용합니다.
- **미확인 홍보 수치 배제**: 근거가 불명확한 수치 표기(예: '17개사' 등)를 배제하고 투명하고 신뢰성 높은 표현('실시간 다이렉트', '대한민국 주요 전업 렌터카사 최저가 비교')을 사용합니다.

### 3) 반응형 및 모바일 360px 최적화 원칙
- **최소 대응 기준 360px**: 갤럭시 폴드 커버 화면 및 소형 디바이스에서 가로 스크롤(오버플로우)이 일절 발생하지 않도록 설계합니다.
- **컨테이너 그리드 정렬**: 모바일 좌우 패딩을 `16px`로 통일하고, 와이드 데스크톱에서는 주요 섹션(헤더, 후기, 최종 CTA, 푸터)을 `1,440px`로 일원화합니다.
- **텍스트 줄바꿈 방지 (`white-space: nowrap`)**: 하단 스티키 바의 `원/월`, 모달 상단 차량 요약 카드의 금액(`521,000원`) 등 중요 금액 텍스트는 단위가 하단으로 떨어지지 않도록 철저히 차단합니다.
- **모바일 핀테크 카드 분할 레이아웃**: 좁은 모바일 화면에서는 무리한 2열 가로 배치를 지양하고, 상단 상세 스펙과 하단 분할 금액 바(예상 월 납입금 - 볼드 금액)로 재구성합니다.

## 5. 섹션별 세부 구현 내용

- **컨테이너 너비**: 1,440px 와이드 규격(`header-container`) 적용.
- **네비게이션 앵커**: 차량 정보, 실시간 최저가 견적, EV5 특장점, 고객 후기, 자주 묻는 질문 스무스 스크롤 연동.
- **CTA 버튼**: `빠른 견적 →` 헤더 다이렉트 버튼 탑재.
- **모바일 드로어**: 햄버거 메뉴를 통한 간결한 풀스크린 네비게이션 및 다이렉트 견적 모달 연동.

### 2. KV 히어로 섹션 (`HeroSection.tsx`)
- **메인 카피**:
  ```text
  기아 EV5,
  일상은 더 넓게.
  장기렌트는 내 조건대로.
  ```
- **메인 CTA**: `EV5 장기렌트 견적받기 →` 단독 배치로 전환 집중도 강화.
- **인터랙티브 컬러 스와치**: 9가지 공식 외장 컬러 선택 시 EV5 차량 렌더링 실시간 전환 (모바일 1행 캡슐 바 레이아웃 유지).
- **제원 스트립**: 휠베이스 2,750mm, 풀플랫 2열 시트, 파노라믹 와이드 디스플레이, 실내 220V V2L (모바일 1열 카드 리스트 자동 변환).

### 3. 실시간 예상 견적 계산기 (`EstimateCalculator.tsx`)
- **상단 헤더**: 좌측 썸네일 실사, 우측 모델명(`EV5`) 배치.
- **월 렌트료 카드**:
  - 상단 소형 캡션: `차량가 기준 월 예상 이용료`
  - 대형 볼드 금액 표기 (예: `521,000원/월`)
  - 하단 안내: `DSR 규제 미적용 · 만기 시 인수/반납 선택 가능` 및 심사 조건 안내.
- **필드 배치 순서**:
  1. **트림 선택 드롭다운**: 공식 6종 트림, 차량가 뱃지, 세부 제원 표기.
  2. **선납금 선택기**: `0%`, `10%(균형형)`, `20%`, `30%` (선택 시 실시간 원화 환산액 표기).
  3. **보증금 선택기**: `0%`, `10%`, `20%`, `30%` (연간 6% 월 렌트료 할인 실시간 차감 반영).
  4. **주행거리 선택기**: `1만`, `1.5만`, `2만(최다)`, `3만`, `무제한` (모바일 5열 균등 정렬).
  5. **계약기간 선택기**: `3년`, `4년`, `5년(장기 이용)`.
  6. **견적 분석 받아보기 버튼**: 선택된 트림, 외장 색상, 계약 조건이 모달로 즉시 자동 전달.

### 4. EV5 하이라이트 & 특장점 (`EV5Features.tsx`)

### 2) 세부 계산 공식
```text
총 계약 개월 수 (termMonths) = termYears * 12

1. 기간별 가중치 (termMultiplier)
   - 5년 (60개월): 1.00 (기준)
   - 4년 (48개월): 1.09
   - 3년 (36개월): 1.21

2. 선납금 원화 금액 및 월 환산 차감액 (소멸성)
   - prepaymentAmount = round(차량가 * (선납비율 / 100))
   - monthlyPrepaymentDeduction = prepaymentAmount / termMonths

3. 보증금 원화 금액 및 연간 6% 월 환산 할인액 (만기 환급/인수금 활용)
   - depositAmount = round(차량가 * (보증금비율 / 100))
   - monthlyDepositDiscount = (depositAmount * 0.06) / 12

4. 연간 주행거리 가감액 (mileageDelta)
   - 10,000km: -15,000원
   - 15,000km: 0원 (기준)
   - 20,000km: +18,000원
   - 30,000km: +45,000원
   - 무제한(-1): +75,000원

5. 최종 월 렌트료 산출
   - 월 렌트료 = (트림 기준 월 렌트료 * termMultiplier)
                - monthlyPrepaymentDeduction
                - monthlyDepositDiscount
                + mileageDelta
   - 100원 단위 반올림 절삭 및 최솟값(250,000원) 보정
```

### 🚀 10. Canonical URL 및 SNS 메타데이터 통합 최적화
- **Canonical 대표 URL 단일화**:
  - 임시 대표 도메인인 `https://rental-car-kia-ev-5.vercel.app/`을 기준으로 `<link rel="canonical">`, `og:url`, JSON-LD `@id` 및 `url`을 단일 HTTPS 엔드포인트로 100% 일치화.
- **주요 SNS 및 메신저 링크 공유 호환성 확보**:
  - **카카오톡 & 페이스북**: 표준 `og:title`, `og:description`, `og:image`, `og:url`을 추출하여 1200×630px 고해상도 리치 프리뷰 카드 렌더링.
  - **네이버 블로그/카페**: OG 크롤러 접근 시 타이틀, 디스크립션, 대표 썸네일 완벽 호환.
  - **X(Twitter)**: `twitter:card="summary_large_image"` 전용 대형 와이드 카드 구성.
  - **인스타그램·유튜브·틱톡**: 외부 링크 연결 시 표준 OG 메타데이터를 안전하게 지원하며, 미지원 전용 비표준 태그(`instagram:*`, `tiktok:*` 등)를 배제하여 표준성 준수.
- **순수 메타데이터 비노출 원칙 준수**:
  - 모든 SNS 메타데이터를 HTML `<head>` 내부에만 배치하고, 화면상에 불필요한 공유 버튼이나 키워드 은닉용 숨김 태그(`display:none`) 일체 배제.
- **다해상도 파비콘 및 PWA 매니페스트 구축**:
  - 기존 핏카 브랜드 전용 파비콘 세트(`favicon.ico`, `16x16`, `32x32`, `48x48`, `apple-touch-icon 180x180`, `site.webmanifest`)를 정적 서빙 경로에 배치하고 HTML `<head>`에 명시적 연결.
