# 기아 EV5 장기렌트 공식 다이렉트 랜딩페이지 (KIA EV5 Direct)

기아의 전용 전동화 준중형 SUV **EV5**의 장기렌트 견적 비교 및 실시간 맞춤 상담 유도를 위한 프리미엄 다이렉트 랜딩페이지입니다.  
화이트·라이트 그레이·블랙의 모노톤과 테크놀로지 민트 포인트를 기반으로 한 **Volterra 미니멀리즘 디자인 시스템**을 적용하였으며, 모바일 최소 360px부터 초고해상도 데스크톱(1440px+)까지 완벽하게 대응합니다.

## 1. 프로젝트 개요

- **프로젝트명**: KIA EV5 장기렌트 다이렉트 비교 랜딩페이지 (`rentalCar_kia_EV5`)
- **타깃 차량**: 기아(KIA) EV5 (Air Standard, Air Long Range, Earth Long Range, GT-line Long Range)
- **핵심 목표**:
  - 투명하고 정확한 실시간 견적 산출 경험 제공
  - 복잡한 렌트 조건(선납금, 주행거리, 기간)을 직관적으로 조작할 수 있는 원스톱 계산기

  - 전 디바이스(모바일 360px ~ 1440px+ 와이드)에서의 무결점 반응형 사용자 경험 제공

## 4. 핵심 작업 규칙 및 원칙 (Work Rules & Principles)

### 1) 스타일링 및 CSS 규칙
- **TailwindCSS 절대 사용 금지**: 오직 순수 Vanilla CSS(`src/styles/index.css`)로만 UI를 구축합니다.
- **CSS 변수 기반 토큰 시스템**:
  - 배경: Clean White (`#ffffff`), Light Gray (`#f8f9fa`, `#edf0f4`)
  - 텍스트: Deep Black (`#0c0d0e`), Body Slate (`#4b5563`, `#64748b`), Light Muted (`#94a3b8`)
  - 브랜드 포인트: Luminous Mint (`#00d2ad`), Deep Tech Mint (`#008b74`)
- **인라인 스타일 지양**: 반응형 오버라이드 및 미디어 쿼리가 정상 작동하도록 인라인 스타일을 배제하고 전용 클래스를 선언하여 관리합니다.

### 2) 카피라이팅 및 신뢰도 검증 규칙 ('17개사' 삭제 등)
- **미확인 홍보 수치 엄격 배제**:
  - 금융사/렌터카사 제휴 수가 객관적으로 검증되지 않은 **'17개사'** 등의 특정 수치 텍스트는 사이트 전체(헤더, 본문, 모달, 푸터, 메타태그)에서 완전히 제거하였습니다.
  - 대체 문구: **'실시간 다이렉트'**, **'대한민국 주요 전업 렌터카사'**, **'실시간 최저가 비교'** 등의 객관적이고 신뢰성 높은 표현으로 일원화합니다.
- **과장 광고성 표현 금지**: '무조건 0원', '신용무관 100% 승인' 등 오해의 소지가 있는 문구를 배제하고 투명한 금융 조건(취등록세/공채/보험료 100% 포함, DSR 미적용)을 명시합니다.

### 3) 모바일 360px 반응형 규칙
- **최소 대응 기준 360px**: 갤럭시 폴드(접힌 화면) 및 구형 소형 모바일 디바이스(360px~375px)에서 가로 스크롤(오버플로우)이 발생하지 않아야 합니다.
- **컨테이너 좌우 패딩 16px 일원화**: 모바일 뷰포트에서 `.container`, `.container-narrow`, `.hero-container-inner`의 좌우 여백을 `16px`로 통일하여 시각적 그리드를 일치시킵니다.
- **줄바꿈 방지 (`white-space: nowrap`)**: 하단 스티키 바의 `원/월` 금액 단위 등 모바일에서 줄바꿈 시 레이아웃이 붕괴되는 텍스트는 반드시 `white-space: nowrap`을 적용합니다.
- **모바일 제원 스트립 1단 전환**: 2열 그리드에서 글자가 쪼개지는 현상을 방지하기 위해 모바일(<=640px)에서는 1열 세로 카드 리스트로 전환합니다.
- **모바일 컬러 스와치 단일 행 유지**: 9가지 컬러 스와치가 2줄로 꺾여 캡슐 바가 찌그러지지 않도록 `flex-wrap: nowrap` 및 22px 버튼 크기로 조절합니다.

### 4) 견적 계산기 레이아웃 순서 규칙
1. **상단 헤더**: 좌측 차량 썸네일 이미지, 우측 `EV5` 모델명 배치 (좌우 위치 변경).
2. **월 렌트료 카드**: 상단에 월 예상 금액을 먼저 배치하고, 금액 바로 아래에 취등록세·공채·자동차세·보험료 포함 및 신용점수 영향 없음 문구를 내장.
3. **이용상품 영역 삭제**: 기존 '장기렌트 / 리스' 탭 형태의 분리 섹션을 제거하고 올인원 장기렌트 혜택으로 통합.
4. **트림 선택기**: 금액 카드 바로 아래에 배치.
5. **선납금 선택기**: 10%(최다 선택), 20%, 30% 버튼 배치.
6. **주행거리 선택기**: 1만km, 2만km(최다 선택), 3만km 버튼 배치.
7. **계약기간 선택기**: 주행거리 아래이자 메인 버튼 바로 위로 이동 (2년, 3년, 5년 최대 할인).
8. **견적 분석 받아보기 버튼**: 최종 하단에 배치하여 클릭 시 입력 조건이 그대로 상담 모달로 연동.

### 5) 네비게이션 및 헤더 규칙
- **관리자 API 메뉴 비노출**: PC 및 모바일 헤더 메뉴에서 관리자 API 버튼을 노출하지 않습니다.
- **모바일 메뉴 간소화**: 모바일 드로어 메뉴에서 후기 건수(예: `(2,125건)`)를 삭제하고 순수 메뉴명만 표시합니다.

### 6) 섹션 배경 및 연결 규칙
- **FAQ 섹션**: 배경색 `#ffffff`, 섹션 타이틀 중앙 정렬.
- **최종 CTA 섹션 (`FinalCtaSection`)**:
  - 외부 배경색: FAQ와 동일한 `#ffffff` 적용.
  - 상단 패딩: `padding-top: 0`으로 FAQ 섹션과 시각적 공백 없이 자연스럽게 연결.
  - 컨테이너 너비: 후기 섹션과 동일한 와이드 `1,440px` 적용.
- **하단 스티키 바 연동**: 350px 이상 스크롤 시 화면 하단에 표시되며, 최종 CTA 섹션(`#final-cta`)이 화면에 진입하면 자동으로 숨겨져 요소 간 겹침을 방지합니다.

## 6. 실시간 견적 산출 알고리즘 및 데이터 구조

견적 서비스는 `src/services/estimateCalculator.ts`에서 단일 책임으로 동작하며, 실제 전업 렌터카사의 감가상각 가중치 및 선납금 환산 방식을 기반으로 구현되었습니다.

### 1) 계산 공식
```text
총 계약 개월 수 (termMonths) = termYears * 12

1. 기간별 가중치 (termMultiplier)
   - 5년 (60개월): 1.00 (기준)
   - 4년 (48개월): 1.09
   - 3년 (36개월): 1.21
   - 2년 (24개월): 1.38

2. 선납금 원화 계산 및 월 환산 차감액
   - prepaymentAmount = round(차량 기본가 * (선납비율 / 100))
   - monthlyPrepaymentDeduction = prepaymentAmount / termMonths

3. 주행거리 가감액 (mileageDelta)
   - 10,000km: -15,000원
   - 15,000km: 0원 (기준)
   - 20,000km: +18,000원
   - 30,000km: +45,000원

4. 월 렌트료 산정
   - 월 렌트료 = (트림 기준 렌트료 * termMultiplier) - monthlyPrepaymentDeduction + mileageDelta
   - 100원 단위 절삭 및 최솟값(250,000원) 보정
```

### 2) 포함 혜택 (All-in-One 장기렌트)
- 취등록세 100% 면제/포함
- 자동차세(연 2회) 100% 포함
- 종합보험료(대인/대물/자손/자차) 전액 포함
- 신용점수 및 DSR(총부채원리금상환비율) 영향 없음
